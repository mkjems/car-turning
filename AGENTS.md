The idea with this project is to make a small racing game in a web component that you can put on you page.

It should be cute a simple when it is embeded on you page and you should be able to drive rounds on a tiny track.

But as soon as you click the make-full-screen button it gets much bigger at turns into a scrolling ciy racing game where you drive on a more elaborate track.

There should be a play button to make sure it has focus so you can use the arrow keys
There should be a go-full-screen button to go full screen.

The aesthetics should be like a gray blue print technical drawing but with shadows like in sketchup

The hard part is to get it to be playable even before you go full screen.
